# Korea Auto Finder
1. Създай безплатен API ключ от XAPI Korea.
2. Копирай `.env.example` като `.env` и постави ключа.
3. Инсталирай Node.js.
4. Изпълни `npm install`.
5. Задай `XAPI_KOREA_KEY` като environment variable.
6. Изпълни `npm start`.
7. Отвори http://localhost:3000

API ключът НЕ е в HTML/браузъра; backend-ът го пази на сървъра.
